## 🚀 Products I've built

> These are commercial products, so their source code is private. Happy to walk through architecture and decisions in an interview.

### 🔧 Taller Pro RD: SaaS for auto repair shops
Multi-tenant platform for mechanic workshops: work orders, customers and vehicles, inventory and billing. Sold on a subscription model with tiered plans (Basic, Professional, Enterprise) and add-on modules.

### 🛒 Point of Sale system
POS platform for retail businesses: sales, inventory, cash register management and reporting.

### 📊 Multi-company accounting API (client project)
Accounting backend built with **NestJS + Prisma + PostgreSQL**: multi-tenant architecture, double-entry bookkeeping, fiscal periods, invoicing compliant with Dominican tax authority rules (NCF / ITBIS), JWT authentication with role-based access control and audit logging.
