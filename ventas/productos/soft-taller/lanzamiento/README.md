# 🚀 Lanzamiento: Semanas 1 y 2

> Arranque: **lunes 23 de noviembre de 2026**. Objetivo de las 2 semanas: **primeras 10 demos agendadas y 2 nuevos clientes**, mientras se prepara la campaña de prórroga de la DGII (detalles a más tardar el 30/11).

## Quién hace qué

Mientras se contrata el equipo, la venta la hace el **fundador** con el material de este kit. Dirección Comercial prepara el material, mide y ajusta.
