# 💼 Departamento Comercial: Ventas y Marketing

> **Manual operativo del departamento comercial.** Aquí está todo lo que el equipo necesita para vender nuestros productos y servicios con método, con medición y con foco en resultados.

**Dirección General Comercial**: responsable de estrategia, metas, presupuesto y resultados de Marketing, Ventas y Customer Success.

---

## 🎯 Para qué existe este departamento

1. **Generar ingresos predecibles y recurrentes** (MRR de los SaaS y contratos de servicios).
2. **Llevar cada producto al cliente correcto** con el mensaje correcto y el canal correcto.
3. **Retener y hacer crecer a cada cliente** después de la venta.

## 🧭 Portafolio que vendemos

| Línea | Producto/Servicio | Modelo de ingreso |
|---|---|---|
| SaaS | **Taller Pro RD**: gestión para talleres mecánicos | Suscripción mensual/anual (Básico, Profesional, Empresarial) + módulos |
| SaaS | **Sistema POS**: punto de venta para retail | Suscripción + implementación |
| Servicios | **Desarrollo a medida** (APIs, contabilidad multiempresa, NCF/ITBIS) | Proyecto + soporte mensual |
| Servicios | **Ciberseguridad**: pentesting web, auditorías, hardening | Proyecto / retainer |
| Educación | **Sirtech Academy**: cursos de ciberseguridad y hacking ético | Cursos, cohortes, formación corporativa |
