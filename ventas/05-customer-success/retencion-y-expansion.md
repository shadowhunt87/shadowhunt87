# Retención y Expansión

## 1. Health score del cliente (0–100)

| Indicador | Peso |
|---|---|
| Uso (frecuencia de inicio de sesión, órdenes/ventas) | 40% |
| Adopción (usuarios activos / contratados, módulos usados) | 20% |
| Soporte (tickets, sentimiento) | 15% |
| Pago al día | 15% |
| NPS / relación | 10% |

🟢 > 75: saludable → buscar expansión y referido · 🟡 50–75: seguimiento · 🔴 < 50: plan de rescate

## 2. Cadencia de contacto por segmento

| Segmento | Contacto |
|---|---|
| Empresarial / multi-sucursal | Revisión mensual + QBR trimestral |
| Profesional | Check-in mensual automatizado + llamada trimestral |
| Básico | Comunicación automatizada (email/WhatsApp) + alertas de riesgo |
| Clientes de ciberseguridad | Reunión de cierre de proyecto + seguimiento de remediación a 30 y 90 días |

## 3. Motores de expansión

| De | A | Disparador |
|---|---|---|
| Taller Pro RD Básico | Profesional | Llega al límite de usuarios o pide inventario/reportes |
| Taller Pro RD | + POS | Taller con venta de repuestos al mostrador |
| Taller Pro RD | + Add-ons (NCF, portal, citas) | Crecimiento de volumen |
| Pentest puntual | Retainer de seguridad | Al entregar el informe y el re-test |
| Pentest | Concientización (Academy B2B) | Hallazgos de ingeniería social o phishing |
| Desarrollo a medida | Soporte mensual + pentest del sistema | Al salir a producción |
| Alumno Academy | Cohorte avanzada / membresía | Al completar un curso |

## 4. Renovaciones
- Contacto **60 días antes** del vencimiento (anuales y retainers).
- Presentar el resumen de valor obtenido (horas ahorradas, vulnerabilidades corregidas, ventas registradas).
- Ofrecer renovación anticipada con beneficio (add-on o mes gratis).

## 5. Proceso de cancelación
1. Toda solicitud de cancelación pasa por una **llamada de retención** con CS.
2. Entender el motivo real y ofrecer una alternativa (pausa de 1–2 meses, cambio de plan, capacitación adicional).
3. Si cancela: registrar el motivo, exportar los datos del cliente y salir en buenos términos (encuesta de salida).
4. Reporte mensual de motivos de churn a Producto y Dirección.

## 6. Programa de referidos y defensores
- Clientes con NPS de 9–10 → invitación al programa de referidos.
- "Talleres Embajadores": descuento permanente a cambio de testimonios, visitas de prospectos y casos de éxito.
