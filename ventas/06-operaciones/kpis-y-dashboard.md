# KPIs y Dashboard Comercial

## 1. Dashboard ejecutivo (Dirección, semanal)

| KPI | Fórmula | Meta `[VALIDAR]` |
|---|---|---|
| **Nuevo MRR** | Σ MRR de clientes nuevos del periodo | Según plan mensual |
| **MRR neto** | Nuevo + expansión − contracción − churn | Crecimiento ≥ 8% mensual |
| **Ingresos de servicios** | Σ cobrado en proyectos y retainers | Según plan |
| **Pipeline ponderado** | Σ (valor × probabilidad de la etapa) | ≥ 3x la meta del mes siguiente |
| **Win rate** | Ganados / (ganados + perdidos) | SaaS ≥ 25%, Servicios ≥ 30% |
| **Ciclo de venta** | Promedio de días de creación a ganado | SaaS < 21, Servicios < 60 |
| **Ticket promedio** | Ingresos / número de ventas | - |
| **CAC** | (Gasto de marketing + ventas) / nuevos clientes | - |
| **LTV** | ARPU × margen bruto / churn mensual | LTV:CAC ≥ 3:1 |
| **CAC payback** | CAC / (ARPU × margen) | < 6 meses |
| **Churn de logos** | Clientes perdidos / clientes al inicio del mes | < 3% |
| **NRR** | (MRR inicio + expansión − contracción − churn) / MRR inicio | ≥ 105% |
| **NPS** | % promotores − % detractores | > 50 |

## 2. Embudo (Marketing + Ventas, semanal)

```
Leads ──▶ MQL ──▶ SQL ──▶ Demos ──▶ Propuestas ──▶ Ganados
 400      150      52       40          18            10      ← ejemplo mensual Taller Pro RD [VALIDAR]
     37%      35%     77%        45%           55%
```

**Cálculo inverso de la meta:** si la meta es 10 clientes/mes con win rate de 25%, se necesitan 40 demos → 52 SQL → 150 MQL → 400 leads. **Así se calcula el presupuesto de marketing y la actividad del SDR.**

## 5. Semáforo de desempeño individual

| Cumplimiento mensual | Acción |
|---|---|
| ≥ 100% 🟢 | Reconocimiento |
| 70% – 99% 🟡 | Coaching enfocado en la etapa más débil del embudo |
| < 70% durante 2 meses 🔴 | Plan de mejora de desempeño (PIP) de 60 días |
